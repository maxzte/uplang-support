# UpLang: Listening Trainer for YouTube Music™ — Support & Feedback

Public issue tracker and privacy policy for the **UpLang** Chrome extension.

## How to Report a Bug or Request a Feature

1. Open the **[Issues](https://github.com/maxzte/uplang-support/issues)** tab.
2. Search existing issues to see if your problem or idea has already been reported.
3. Click **New issue** and choose a template:
   - **Bug report** — something isn't working as expected on YouTube Music™.
   - **Feature request** — an idea to improve UpLang.
4. *(For bugs)* Open the UpLang extension popup and click **Copy error log**, then paste the log into the issue (remove any personal song names if you prefer).

## Useful Details to Include
- **Extension version** (e.g. `1.0.0`, visible in `chrome://extensions/`)
- **Browser & OS** (e.g. Chrome 138 on macOS / Windows)
- **Song / URL** where the issue occurred (if lyrics/sync related)
- **Screenshots** or steps to reproduce
